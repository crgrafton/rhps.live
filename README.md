# rhps.live - The Rocky Horror Picture Show Shadowcast Finder

`rhps.live` is a community-driven, open-access directory and interactive map for finding regular live *The Rocky Horror Picture Show* shadowcast performances worldwide.

## Features
- 🗺️ **Interactive Global Map**: Browse regular shadowcast venues with live showtimes, tickets, and directions.
- 📍 **Automatic Geolocation**: Defaults to requesting user location to find the closest shadowcast.
- 🌟 **Weekly Featured Cast**: Automatically rotates a featured shadowcast on the homepage each week.
- 📝 **Cast Registration**: Built-in registration modal for shadowcasts to submit their details to the plaintext database.
- 📄 **Plaintext Database**: All casts and venues are maintained in [`docs/data/casts.json`](docs/data/casts.json).
- ⚖️ **Legal & IP Compliant**: Operates under nominative fair use with full non-affiliation disclaimers.

## Adding or Updating a Cast
Cast data is stored in [`docs/data/casts.json`](docs/data/casts.json). You can register a cast directly on the website using the **Register Your Cast** button, or submit a Pull Request adding your cast's JSON entry.
